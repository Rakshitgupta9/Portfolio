🏡 Airbnb Listings Data Analysis Dashboard (Tableau)

View on GitHub Live Dashboard

📋 Overview

This Tableau dashboard analyzes Airbnb Listings 2016 data to uncover insights related to pricing, revenue trends, and geographic distribution of listings.

The dashboard enables interactive exploration of Airbnb business performance using location-based analysis, revenue trends, and pricing segmentation across different property characteristics.

✨ Key Insights

📍 Geographic Price Analysis

  • Mapped Airbnb price distribution across zipcodes
  • Identified high-value geographic regions

📈 Revenue Trend Analysis

  • Analyzed weekly revenue performance over time
  • Observed seasonal pricing and revenue patterns

🛏 Property Pricing Insights

  • Explored pricing variation by bedroom count
  • Identified relationship between listing size and pricing

📊 Zipcode Comparison

  • Compared average Airbnb prices across regions
  • Highlighted top-performing listing areas

🎛 Interactive Dashboarding

  • Built dynamic Tableau dashboard with interactive exploration
  • Enabled user-driven filtering and data analysis

🧹 Data Preparation

  • Structured raw data for visualization and analysis
