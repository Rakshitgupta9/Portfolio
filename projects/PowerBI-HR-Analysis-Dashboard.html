👥 HR Analytics Dashboard (Power BI)

View on GitHub Download Dataset

📋 Overview

This project presents an interactive HR Analytics Dashboard built using Power BI to analyze employee attrition, workforce demographics, salary distribution, employee satisfaction, and organizational trends.

The dashboard helps identify attrition patterns, workforce behavior, and potential retention risks through interactive KPI tracking, drill-down analysis, and business-focused visual storytelling.

✨ Key Insights

📉 Employee Attrition Analysis

  • Analyzed attrition across age groups, salary slabs, and tenure
  • Identified high-risk employee segments

👥 Workforce Demographics

  • Explored workforce distribution by gender, age, and department
  • Compared employee composition across categories

💰 Compensation Insights

  • Analyzed salary distribution and attrition correlation
  • Identified salary-related retention trends

😊 Employee Satisfaction Metrics

  • Tracked job satisfaction and work-life balance indicators
  • Measured workforce sentiment patterns

📊 Drill-Down Analytics

  • Built hierarchical drill-down charts for deeper exploration
  • Enabled dynamic workforce analysis across dimensions

🧹 Data Cleaning & Preparation

  • Processed 1,480 HR records with duplicate removal
  • Prepared structured HR data for analysis and reporting
